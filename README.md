# 📋 Flutter To-Do List Application

A clean, modern, and lightweight To-Do List application built with **Flutter** and **Dart**. Designed to help users manage daily tasks, track productivity, and organize pending vs. completed goals effortlessly.

---

## 🚀 Key Features

* ➕ **Add New Tasks:** Create tasks with descriptive titles and custom details.
* ✏️ **Edit & Update:** Modify existing task information and adjust descriptions anytime.
* ✅ **Task Completion Status:** Toggle tasks between *Pending* and *Completed* states with visual indicators.
* 🗑️ **Delete Tasks:** Remove completed or unwanted tasks from the list.
* 📋 **Task Management:** View all tasks in one centralized, organized dashboard.
* ⚡ **Optimized Performance:** Fast, responsive UI conforming to Material Design 3 guidelines.

---

## 📱 App Screens & Navigation

### 1. Home Screen
* Displays the complete list of tasks.
* Visual status indicators (Pending vs. Completed).
* Quick-action buttons to edit, toggle completion, or delete tasks.
* Floating Action Button (FAB) for swift navigation to task creation.

### 2. Add Task Screen
* Input fields for **Task Title** and **Task Description**.
* Form validation to ensure required fields are filled.
* Save / Add button to persist the new task.

### 3. Task Details & Edit Screen
* In-depth view of task details.
* Inline editing capability for task information.
* Direct toggle to mark task as completed or reopen.
